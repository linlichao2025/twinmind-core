
# TwinMind PRD v0.1

## 1. 产品定位
TwinMind 是一个"人机合一"的数字分身基座。用户通过六维度问卷完成人格对齐，AI 分身共享用户的价值观、决策逻辑、知识图谱、目标体系、表达风格和关系网络。不是扮演，是合一。

## 2. 目标用户
- 超级个体创业者、独立开发者、自由职业者
- 有大量决策需求、需要"第二大脑"辅助思考的人

## 3. 核心功能（MVP）
1. **人格对齐问卷**：六维度结构化输入 → 生成人格文件（YAML/JSON）
2. **对话引擎**：每次对话前注入人格文件到 system prompt，AI 在人格框架内回答
3. **记忆同步**：对话后自动提取关键信息写入记忆库，下次对话自动检索注入
4. **目标追踪**：用户设定目标 → AI 拆解路径 → 每日跟进 → 动态调整

## 4. 六维度对齐模型
- 价值观对齐：优先级排序、红线、鄙视/敬佩、驱动力
- 决策逻辑：流程、风险评估、压力反应、弱点、信息源
- 知识图谱：技能树、踩坑、研究方向、信息源
- 目标体系：短/中/长期目标、代价、调整条件
- 表达风格：口吻、变体、口头禅、节奏
- 关系网络：关键人物、财务关系、项目关系

## 5. 技术架构
- 前端：问卷页 + 对话页（React/Vue）
- 后端：FastAPI（Python）
- 模型：Claude API（人格注入）+ 向量数据库（记忆检索）
- 存储：人格文件（YAML/JSON）+ 对话记录（PostgreSQL）+ 记忆向量

## 6. 开发排期
- Week 1：问卷设计 + 人格文件结构 + 对话引擎 demo
- Week 2-3：记忆同步模块
- Week 4-5：目标追踪模块
- Week 6-7：内测（10人）+ 迭代
- Week 8：公测上线

## 7. 商业化
- 免费版：基础人格对齐 + 每日对话
- 个人版：深度对齐 + 记忆同步 + 目标追踪（99元/月）
- 专业版：多模态接入 + 主动驱动 + 数据看板（299元/月）
