# TwinMind / 双生意识

> 人机合一的超级个体引擎。让每个个体拥有自己的数字分身——共享记忆、价值观、目标与决策逻辑。

## 愿景

不是 AI 扮演你，而是 AI **成为你的第二大脑**。六维度人格对齐 + 记忆同步 + 目标驱动，打造真正"懂你"的数字分身。

## 核心模块

- **Persona Engine**：六维度人格对齐（价值观/决策逻辑/知识图谱/目标体系/表达风格/关系网络）
- **Memory Sync**：对话后自动提取关键决策、情绪、结果，写入记忆库
- **Goal Driver**：目标设定→路径拆解→每日跟进→动态调整

## 技术栈

- LLM：Claude API（长上下文人格注入）
- 向量数据库：Supabase / Pinecone
- 后端：Python FastAPI
- 前端：React（后期）
- 部署：云服务器
